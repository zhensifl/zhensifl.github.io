# WordStep 英语词汇训练

一个无需安装、打开即用的本地英语背词网站。学习数据保存在当前浏览器的 `localStorage` 中。

## 使用方法

双击 `index.html`，或在浏览器中打开它即可开始学习。

## 学习机制

- 每个词先进行“英 → 中”或“中 → 英”辨义，再完成主动拼写。
- 拼写错误时展示正确答案，并要求重新输入；只有拼写正确才能继续。
- 默认复习阶梯为 1、2、4、7、15、30、60 天。
- 答错会降低当前记忆阶段；累计错误越多，下次复习间隔越短。
- 每天优先完成到期复习，再加入设定数量的新词。
- 可设置每日 5–30 个新词；到期复习不受新词上限影响。
- 学习记录、连续天数、易错词与阶段分布会自动保存。

## 词库

内置 70 个起步词汇，覆盖居家生活、饮食购物、出行问路、社交沟通、办公沟通和协作反馈 6 个场景。代码中的 `WORDS` 数组可以继续扩充。
