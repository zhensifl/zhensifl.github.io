# WordStep 英语词汇训练

一个无需安装、打开即用的英语背词网站。未登录时数据保存在当前浏览器中；登录后会通过 Supabase 自动同步到其他设备。

## 使用方法

双击 `index.html`，或在浏览器中打开它即可开始学习。

## 学习机制

- 首次使用可完成 12 题水平测试，从 A2、B1 或 B2 的合适难度开始。
- 可选择综合训练、认词与拼写、听音辨义或听写强化模式。
- 拼写错误时展示正确答案，并要求重新输入；只有拼写正确才能继续。
- 每道辨义题和拼写题都可标记“不认识”；这类词会增加复习权重并优先出现在后续到期复习中，连续答对后权重逐步降低。
- 查看结果后可按 `Enter` 进入拼写或下一个单词。
- 复习间隔按单词稳定度、难度、最近回忆概率与答题表现动态计算；无需每题手动选择难度。
- 旧错误会随时间降低权重，不会永久压低复习周期。
- 每天优先完成到期复习，再加入设定数量的新词。
- 每日新词和复习词分别设置：新词可设为 5–70 个，复习词每天最多安排 150 个，二者互不挤占。
- 可设置每日 5–70 个新词；到期复习不受新词上限影响。
- 英文选中文题的每个选项都显示词性，并在单词下方提供双语例句帮助理解语境。
- 学习记录、连续天数、易错词、场景掌握度、近期正确率与明日预计复习会自动统计。
- 支持邮箱注册和登录；首次登录会合并当前设备与云端记录，之后可在手机、平板和电脑之间同步。
- 支持导出与导入学习记录、重置密码、安装到手机桌面以及离线学习。
- 词库和学习卡片均可点击星标收藏；独立“收藏词库”默认隐藏中文，点击英文展开释义和双语例句，喇叭独立播放英语发音。
- 收藏使用独立于练习记录的逐词状态，登录后随进度同步；取消收藏保留删除标记，防止旧设备把它重新合并回来。重置学习进度会保留收藏；备份也包含收藏。

## 词库

词库按日常交流与赴美打工场景筛选，覆盖居家租房、饮食购物、出行交通、健康身体、社交沟通，以及泳池救生、餐饮服务、零售收银、酒店客房和排班薪资。移除冷门宗教、历史、文学、专门科学术语和专名；常用词若原释义过于偏门，则修正义项与例句。完整条目数量以词库页为准，单词与固定表达都计为一个学习条目。

新增岗位核心词会优先进入相应等级的新学队列；可在词库中按场景筛选。原词库高频排序参考 `wordfreq`，英汉释义与音标参考 MIT 许可的 ECDICT；原等级参考 CEFR-J 与 EFLLex。新增场景词的 A2/B1/B2 是教学难度估计，不声称为官方逐词认证。

保留词的 ID 不变，新增词使用独立 ID 范围。被筛除的词不再进入新学、复习或干扰选项，但其历史学习记录仍保存在本机/云端，不删除账户数据。

岗位场景参考 [美国红十字会救生员课程](https://www.redcross.org/take-a-class/lifeguarding/lifeguard-preparation)、[O*NET 救生员职责](https://www.onetonline.org/link/summary/33-9092.00)、[快餐与柜台服务](https://www.onetonline.org/link/custom/35-3023.00)、[收银员](https://www.onetonline.org/link/summary/41-2011.00)与[客房保洁](https://www.onetonline.org/link/summary/37-2012.00)。词义和例句用于英语学习，不替代救生认证、现场培训或雇主操作规程，也不构成医疗、工资或签证建议。

双语例句不超过 10 个英文词，优先选择简短的日常场景。较长、复杂和词义错配的句子改写为带中文翻译的学习短句。原语料来源包括 Tatoeba、ALT 和 WikiMatrix；编辑后的短句标注独立来源。详细来源与许可见 `EXAMPLE-DATA-LICENSES.md`。

词库与学习卡片提供扬声器按钮，优先使用浏览器英文语音，缺少英文音色时使用在线词典发音。在线发音需要网络连接。
